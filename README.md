# Recruitment Management System

A web-based Recruitment Management System developed using Java, JSP, Servlets, JDBC, MySQL, and Apache Tomcat.

## Features
- User Registration
- User Login
- Candidate Dashboard
- Profile Management
- Resume Upload
- Admin Dashboard
- View Candidates
- Delete Candidates
- Session Management

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat 10.1
